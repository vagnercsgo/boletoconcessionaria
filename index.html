Como usar

  • Cole o código ou a linha digitável na página correspondente.
  • O sistema remove automaticamente espaços, pontos e outros caracteres não numéricos.
  • A conversão e os dígitos verificadores são calculados localmente no navegador.
  • Os botões Copiar copiam somente os números.
